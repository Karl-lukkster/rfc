Core
These rules define the format.
Singleton
Thus no two chips or cards of the same name can be run.
Chips of the same name but different codes are considered to be the same chip. For instance: VarSwrd C and VarSwrd D cannot be run in the same folder.
In SF2, starred cards are considered the same as non-starred cards. Thus one cannot have both Cannon and Cannon 3star in the same folder.
No Navi Summons
In Battle Network, this includes all Star chips ().
In Star Force, this includes almost all Mega Cards. The lone exception being SF2's King Grandeur.
Online exclusives are banned
Requiring online in order to obtain an option makes it harder to build the perfect folder.
This bans 2 giga chips from BN3, as they aren't accessable without online.
This includes real brotherbands in Star Force.
Bans
These options were deemed too strong.
BN3's Folderback
BN3's Folderback is arguably the best chip across the whole series. Folderback works against the limitations of a singleton format.
Convenience
These rules exist to ease participation in the format.
Trader exclusives are banned
Chip Traders are random, ignoring BN1's RNG manipulations. If a chip or code is only available via Chip Trader, it could require extensive time to obtain.
